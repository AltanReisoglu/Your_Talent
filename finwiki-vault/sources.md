# FinWiki Sources Registry

This file is the human-readable source registry. Machine-readable source
tracking lives in `wiki/.manifest.json`.

## Source Quality Hierarchy

1. Official primary sources: regulators, central banks, exchanges, company
   filings, audited reports, KAP/SEC/EDGAR-style disclosures.
2. Reputable data providers and financial institutions with methodology notes.
3. Established financial media for event chronology and context.
4. Academic papers and technical reports for models and frameworks.
5. LLM synthesis only for conceptual glue, never for market data or regulated claims.
